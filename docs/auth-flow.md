# 🔒 Аутентификация, сессии и подтверждение через uCaller

Система безопасности построена на базе модуля `nuxt-auth-utils`, реляционной модели PostgreSQL (`users` + `roles`), **Redis** для временных сессий и сервиса **uCaller.ru** для верификации номеров телефонов с помощью входящего звонка (Flash Call).

## Жизненный цикл пользователя и аутентификация

1. **Инициация отправки кода / звонка (`POST /api/auth/send-code`)**:
   - Пользователь вводит номер телефона и пароль.
   - Сервер проверяет наличие номера в таблице `users` (в системе могут регистрироваться только предварительно добавленные администратором абоненты).
   - Если пользователь уже активирован (`activated_at !== null`), возвращается ошибка.
   - Сервер обращается к внешнему API **uCaller** (`https://api.ucaller.ru/v1.0/initCall`) с использованием Bearer-авторизации (`UCALLER_SECRET_KEY.UCALLER_SERVICE_ID`).
   - uCaller инициирует звонок на номер пользователя, возвращая код подтверждения.
   - Временный черновик регистрации (включая хэш пароля через `bcryptjs` и код uCaller) сохраняется в **Redis** с ключом `pending_reg:<phone>` и TTL **3 минуты (180 сек)**.

2. **Подтверждение и завершение регистрации**:
   - Пользователь подтверждает звонок, после чего создается защищенная куки-сессия, проставляется дата активации (`activated_at`), и аккаунт переходит в активный статус.

3. **Вход в систему (`POST /api/auth/login`)**:
   - Проверяется совпадение учетных данных.
   - При успешной проверке создается сессия через `nuxt-auth-utils`.
