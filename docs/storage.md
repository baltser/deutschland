# 📁 Управление файлами и интеграция с MinIO

Для хранения пользовательских аватаров и медиафайлов используется локальное объектное хранилище **MinIO**, совместимое с S3 API.

## Архитектура хранилища

- **Бакет по умолчанию:** `dnz-uploads`
- **Структура путей:** Файлы сохраняются в директорию `avatars/` с уникальными UUID-именами (например, `avatars/240b14c4-4319-4777.jpeg`), чтобы избежать коллизий имен.

## Интеграция в коде

- **Инициализация:** Настройка клиента S3 / MinIO находится в `server/utils/minio.ts`.
- **Загрузка:** Функция `uploadFileToMinio()` принимает бинарный буфер, тип файла и папку, возвращая относительный путь для сохранения в базе данных (`avatar_path`).
- **Раздача файлов:** Эндпоинты бэкенда отдают файлы пользователям через безопасный проксирующий слой или прямые ссылки хранилища.

# 🗄 Управление состоянием (Pinia Stores)

В клиентской части приложения (`app/stores/`) для управления глобальными данными и кешированием используются сторы **Pinia**. Все сторы типизированы с помощью TypeScript, взаимодействуют с Nitro API и интегрированы с системой нотификаций (`useToast` из Nuxt UI).

---

## 1. `adminAddressesStore` (`adminAddresses.ts`)
Управление физическими адресами и объектами в административной панели.

* **Состояние (`state`):**
  * `addresses`: Массив объектов `AddressItem[]` (включает связанный список жильцов/клиентов через промежуточную таблицу).
  * `loading`: Флаг загрузки (`boolean`).
  * `error`: Текст ошибки или `null`.

* **Основные действия (`actions`):**
  * `fetchAddresses()`: Загрузка списка всех адресов с сервера (`GET /api/admin/addresses`).
  * `createAddress(addressText: string)`: Создание нового адреса (`POST /api/admin/addresses`), автоматическое обновление списка и вывод уведомления.

---

## 2. `adminClientsStore` (`adminClients.ts`)
Управление данными клиентов и привязанными к ним объектами неждвижимости.

* **Состояние (`state`):**
  * `clients`: Массив объектов `ClientItem[]` (содержит данные пользователя и массив привязанных адресов).
  * `loading`: Флаг загрузки.
  * `error`: Ошибка или `null`.

* **Основные действия (`actions`):**
  * `fetchClients()`: Получение списка клиентов с их адресами (`GET /api/admin/clients`).

---

## 3. `adminUsersStore` (`adminUsers.ts`)
Управление сотрудниками системы (администраторы, монтажники, менеджеры).

* **Состояние (`state`):**
  * `users`: Массив объектов `AdminUserItem[]`.
  * `loading`: Флаг загрузки.
  * `error`: Ошибка или `null`.

* **Основные действия (`actions`):**
  * `fetchUsers()`: Загрузка списка сотрудников (`GET /api/admin/users`).
  * `updateUser(userId: number, payload: Partial<AdminUserItem>)`: Частичное обновление данных пользователя (`PATCH /api/admin/users/[id]`) с мгновенным локальным обновлением массива без повторного запроса.
